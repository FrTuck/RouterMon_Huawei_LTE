# Security Policy / Безопасность

## Модель угроз (кратко)

RouterMon Huawei LTE — **локальный** инструмент. Веб-сервер слушает только `127.0.0.1`
и не доступен из сети. Он предназначен для личного компьютера в доверенной локальной сети.

Что уже сделано для защиты:

- Привязка только к `127.0.0.1` (не к `0.0.0.0`).
- Пароль роутера — только в оперативной памяти, не пишется на диск и в логи; по сети при входе
  уходит криптографический хеш (SCRAM-SHA-256 или SHA-256), а не сам пароль.
- Защита управляющих запросов (`/ctl/...`) от межсайтовых атак: проверка заголовков `Host`
  (DNS-rebinding), `Origin` и `Content-Type` (CSRF); ограничение размера тела запроса.
- Экранирование пользовательских значений, уходящих в XML-запросы роутеру.
- Нет внешних зависимостей, облака и телеметрии.

Известные ограничения (см. также раздел «Риски» в README):

- Пока панель запущена и выполнен вход, ею может пользоваться любой процесс на том же
  компьютере (localhost). Рассчитано на личную машину.
- Связь с роутером идёт по HTTP (как и штатный веб-интерфейс роутера).
- Готовый `.exe` не подписан.

## Как сообщить об уязвимости

Пожалуйста, **не описывайте уязвимость в публичных issue**. Используйте приватный канал
GitHub: вкладка **Security → Report a vulnerability** (Private vulnerability reporting)
в этом репозитории. Если он недоступен — создайте issue с минимумом деталей и пометкой
«security», и сопровождающий свяжется с вами для приватного обсуждения.

Поддерживаемая версия — последняя в ветке `main`.
