# RouterMon Huawei LTE (B818 LTE Panel)

> Local monitoring & control dashboard for Huawei HiLink LTE routers (B818 and others).
> Reads the router's HTTP API and shows signal, traffic and status in your browser; lets you
> change LTE bands, scan bands and reboot. Pure Python stdlib, no dependencies. UI is in Russian.

Локальный дашборд и «пульт» для роутера **Huawei B818-260** и других модемов/роутеров Huawei
с веб-интерфейсом **HiLink**. Опрашивает роутер по его HTTP-API и показывает в браузере сигнал,
трафик и статус, а также позволяет менять диапазоны LTE, сканировать их и перезагружать роутер.

Написано на **чистом Python** (только стандартная библиотека) — для запуска из исходников
ничего ставить не нужно; для раздачи есть сборка в один `.exe`.

---

## Возможности

- **Сигнал LTE** — RSRP, RSRQ, SINR, RSSI с цветовой оценкой качества, плюс «палочки» 0–5.
- **CELL & BAND** — Band, Cell ID, eNodeB, PCI, EARFCN, ширина полосы и частоты.
- **Скорость сейчас** — приём/передача, Mbps.
- **Трафик** — за сессию, за месяц, за всё время.
- **Статус** — оператор, тип сети (LTE/5G…), состояние подключения прямо в визуализации сигнала.
- **Устройство** — модель, прошивка, IMEI/IMSI/ICCID, WAN IP, аптайм.
- **Управление** (после входа) — смена разрешённых диапазонов LTE (Band), перезагрузка роутера.
- **Сканер диапазонов** (отдельная вкладка) — по очереди проверяет каждый Band и показывает,
  какие диапазоны доступны по каждой соте (Cell ID) и с каким сигналом.
- **Индикатор обмена** панель↔роутер, светлая/тёмная тема, работа на телефоне.

Мониторинг (оператор, статус, трафик, сигнал «в палочках») доступен **без пароля**; точный
сигнал, данные устройства и управление — после входа паролем веб-интерфейса роутера.

---

## Минимальные требования

**Запуск готового `.exe` (Windows):**
- Windows 10/11 (64-бит). Больше ничего — Python не нужен.
- Роутер Huawei с веб-интерфейсом HiLink в той же локальной сети.
- Современный браузер (открывается автоматически).

**Запуск из исходников (любая ОС):**
- **Python 3.8+** (проверено на 3.13). Только стандартная библиотека, внешних пакетов нет.
- Роутер Huawei HiLink в той же сети; его адрес (обычно `192.168.1.1` или `192.168.8.1`) и,
  для расширенных функций, пароль веб-интерфейса.

**Сборка `.exe` из исходников:**
- Windows + Python, **PyInstaller** (`build.cmd` ставит его сам).

## Установка и запуск

### Вариант 1. Готовый `.exe` (проще всего, Python не нужен)

Соберите `.exe` командой `build.cmd` (см. ниже) или скачайте из раздела **Releases** репозитория.
Запуск — двойной клик по `B818-LTE-Panel.exe`:

1. Поднимается локальная панель и **сама открывается вкладка браузера** на `http://localhost:8099/`.
2. В окне входа укажите **адрес роутера** (по умолчанию `192.168.1.1`; у части Huawei — `192.168.8.1`)
   и **пароль** (при необходимости — логин, по умолчанию `admin`). Можно нажать «Без входа» —
   тогда доступен мониторинг без управления.
3. Остановить панель — кнопка **«Выйти»** в правом верхнем углу (или снять процесс
   `B818-LTE-Panel.exe` в Диспетчере задач). Окна консоли нет — работает тихо.

> При первом запуске Windows SmartScreen может предупредить о «неизвестном издателе»
> (файл не подписан): «Подробнее» → «Выполнить в любом случае». Антивирусы иногда ложно
> реагируют на программы, собранные PyInstaller, — это ожидаемо для самосборного `.exe`.
> Если не доверяете бинарнику — запускайте из исходников или соберите `.exe` сами.

### Вариант 2. Из исходников (нужен Python)

**Windows:** двойной клик по **`start.cmd`** (спросит пароль; Enter — открыть без входа).

**Командная строка:**

```powershell
py b818panel.py                       # без входа (трафик, статус, сигнал «в палочках»)
py b818panel.py --ask-password        # спросит пароль в консоли
py b818panel.py --password СЕКРЕТ      # передать пароль сразу (см. риски ниже)
py b818panel.py --router 192.168.1.1 --port 8099
```

Параметры можно задать и переменными окружения: `B818_ROUTER`, `B818_USER`,
`B818_PASSWORD`, `B818_PORT`.

### Вариант 3. Собрать `.exe`

Двойной клик по **`build.cmd`** (нужен установленный Python). Поставит PyInstaller и соберёт
`dist\B818-LTE-Panel.exe` — самодостаточный файл, который можно раздавать.

## Зачем пароль

| Без пароля | С паролем (вход в веб-интерфейс роутера) |
|---|---|
| оператор, тип сети, статус | всё из левого столбца, плюс: |
| трафик: сессия, месяц, всего | точный сигнал **RSRP / RSRQ / SINR / RSSI** |
| скорость приёма/передачи | **Band, Cell ID, eNodeB, PCI, EARFCN**, частоты |
| сигнал «в палочках» (0–5) | модель, прошивка, IMEI/IMSI/ICCID, WAN IP; смена Band; перезагрузка; сканер |

Пароль — тот же, что для входа на веб-интерфейс роутера. У B818 с заводскими настройками он
печатается на наклейке снизу. Панель сама определяет способ входа: **SCRAM-SHA-256** (прошивки
10.x+) или старый SHA-256 (`/api/user/login`).

## Совместимость

Панель работает через стандартный HiLink-API, поэтому в целом подходит для многих роутеров Huawei:

- **B818-260 / B818-263** — проверено/ожидается полная совместимость (одна линейка прошивок).
- **Другие LTE из семейства B\*** (B525, B528, B535, B612, B618, B311, B737 и т. п.) — мониторинг
  без пароля работает почти наверняка; точный сигнал, смена Band и перезагрузка — на свежих
  прошивках (10.x+). Набор диапазонов панель читает у самого роутера и подстраивается.
- **Привязка к соте** через API на стоковой прошивке B818 **не поддерживается** (роутер отклоняет
  запрос) — это ограничение прошивки, не панели.
- **5G-модели** — LTE-часть покажется, специфичные поля 5G (NR) пока не выводятся.

Если на другом роутере вход не проходит — пришлите код ошибки, метод входа можно доработать.

## Безопасность

- Панель слушает **только `127.0.0.1`** (localhost) — из сети не видна.
- Пароль роутера держится **только в оперативной памяти** процесса на время работы, **не пишется
  на диск и в логи**. По сети при входе уходит не сам пароль, а криптографический хеш (SCRAM).
- Управляющие запросы защищены от межсайтовых атак: проверяются заголовки `Host` (от DNS-rebinding),
  `Origin` и тип контента (от CSRF); тело запроса ограничено по размеру. Значения, уходящие в
  XML-запросы роутеру, экранируются.
- Нет облака, телеметрии и внешних обращений: панель общается только с указанным роутером
  (и открывает `localhost` в браузере). Внешних зависимостей нет.

Подробнее о модели угроз и ответственном раскрытии — в [SECURITY.md](SECURITY.md).

## Риски и ограничения

- **Сканер диапазонов и смена Band разрывают интернет.** Сканер по очереди переключает роутер на
  каждый диапазон — на это время (полный проход ~5 минут) связь пропадает. Смена Band и перезагрузка
  тоже кратковременно рвут соединение. Не запускайте во время важной загрузки, звонка или игры.
- **Перезагрузка роутера** — очевидно, прерывает работу сети на 1–2 минуты. Выполняется только по
  кнопке с подтверждением.
- **Доступ локального пользователя.** Пока панель запущена и выполнен вход, любой процесс/пользователь
  на этом же компьютере может пользоваться панелью (localhost). Рассчитано на личный компьютер.
- **Передача пароля в командной строке** (`--password`) видна в списке процессов и может попасть в
  историю команд. Предпочтительнее ввод на странице или `--ask-password`.
- **Связь с роутером — по HTTP** (как и у штатного веб-интерфейса роутера): данные идут по локальной
  сети без шифрования. Сам пароль при этом по сети в открытом виде не передаётся (хеш SCRAM).
- **`.exe` не подписан** — возможны предупреждения SmartScreen/антивируса.
- Инструмент **неофициальный**, не связан с Huawei; используется на свой риск.

## Если что-то не так

| Признак | Что проверить |
|---|---|
| «Не удалось связаться с роутером» | адрес роутера (`192.168.1.1` / `192.168.8.1`), что вы в его сети |
| «не вошли», код `108006` | пароль/логин веб-интерфейса |
| код `108005` | слишком много сессий — закройте веб-интерфейс роутера в других вкладках, подождите |
| код `108007` | много попыток входа — роутер временно заблокировал, подождите минуту |
| Сигнал/устройство пустые, «нужен вход» | запущено без пароля — войдите на странице |
| Порт занят | панель сама возьмёт следующий свободный; адрес печатается в консоли |

## Как устроено

- `b818panel.py` — локальный веб-сервер (стандартная библиотека). Логинится в роутер, опрашивает
  `/api/...` HiLink и отдаёт объединённый JSON на `/api/data`; управляющие действия — через `/ctl/...`.
- `dashboard.html` — вся страница одним файлом (без сборки и внешних зависимостей), раз в 3 с
  запрашивает `/api/data` и рисует панель. Отдаётся с localhost.
- `build.cmd` — сборка `.exe` через PyInstaller; `start.cmd` — быстрый запуск из исходников.
